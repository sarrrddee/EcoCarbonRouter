# EcoCarbonRouter 🌍

A production-ready Stacks blockchain smart contract for managing carbon offset credits as non-fungible tokens (NFTs).

## Overview

EcoCarbonRouter is a comprehensive carbon offset token router system that enables organizations and individuals to create, manage, and retire carbon offset credits on the Stacks blockchain. Each carbon offset is represented as a unique NFT, ensuring transparency, traceability, and verifiability of environmental impact claims.

## Features

### 🌱 Project Management
- **Register Projects**: Admin-controlled creation of carbon offset projects
- **Dynamic Pricing**: Set custom pricing per project
- **Mint Caps**: Control maximum token supply per project
- **Project Verification**: Mark projects as verified for credibility
- **Owner Controls**: Project owners can update pricing, caps, and metadata

### 💳 Token Operations
- **NFT-Based Credits**: Each offset is a unique, tradeable NFT token
- **Minting on Purchase**: Automatic NFT generation when users buy offsets
- **Token Retirement**: Retire tokens to claim carbon offsets
- **Unique URIs**: Store metadata references for each token
- **Ownership Tracking**: Full NFT ownership and transfer support

### 💰 Financial Controls
- **STX Payments**: Secure Stacks (STX) cryptocurrency payment processing
- **Treasury Management**: Centralized fund collection and withdrawal
- **Admin Withdrawals**: Flexible withdrawal to specified addresses
- **Balance Tracking**: Real-time fund balance monitoring

### 🔒 Security & Access Control
- **Role-Based Access**: Admin, owner, and user permission levels
- **Input Validation**: Comprehensive parameter validation
- **Cap Enforcement**: Prevents over-minting beyond project caps
- **Error Handling**: 10 distinct error codes for clear failure messages
- **Safe Transfers**: Secure STX transfer operations
